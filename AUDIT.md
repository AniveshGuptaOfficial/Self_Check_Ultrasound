## 2. Corrections to the previous audit
- Test count: README said 21, audit said 31; the suite had 36 tests in 8 modules. It now has 56 (41 new/updated + 15 unchanged).
- Quality metrics: README (MAE 1.738, RMSE 2.258) and the audit (MAE 1.516, RMSE 1.838) disagreed; RMSE 1.838 is implausible for r = 0.495. Re-run on TEST split reports MAE 2.168 [2.033, 2.322], Pearson r = 0.411 [0.332, 0.485].
- "1,500 validation frames", "Smooth L1 / Adam": the scripts use 300 val frames by default, `MSELoss` and `AdamW`.
- "94.4% cause accuracy on 5 views": superseded by `scripts/evaluate_cause_classifier.py` reporting 81.0% accuracy on held-out test synthetic faults and AUROC = 0.701 vs real expert grades.
- "100% correct triage": the old simulator forced adequacy from ground-truth severity and guaranteed recovery. Superseded by the leakage-free simulator in `trained_models+fitted_adequacy` mode.
- "CNN outperformed classical (50.3% vs 49.7%)": the new paired bootstrap on TEST reports difference is statistically significant in favor of the classical spatial baseline (0.713 vs 0.370) on current sample budgets.
- "0 corrupted / 100% Full HD": verified by `build_manifest.py --validate` opening all 37,736 images.

## 3. Evidence classes (keep separate in any paper)

- Synthetic: all fault-diagnosis accuracy on injected faults, all closed-loop trajectories (fault injected, compliance simulated).
